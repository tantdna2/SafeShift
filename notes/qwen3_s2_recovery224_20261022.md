## Observation contract

Per-image memory observations surround preparation, native generate, persistence,
clear, adapter return and sealed CPU replay. Passive hooks on the native outer
conditional-generation forward and vision module distinguish prefill and each
decode call. Hooks return None, do not edit outputs and retain no tensor history.
Their module placement follows the
[pinned Transformers 4.57.1 Qwen3 source](https://github.com/huggingface/transformers/blob/v4.57.1/src/transformers/models/qwen3_vl/modeling_qwen3_vl.py).
All observations include run/attempt, recovery/original ordinal, stage, UTC and
monotonic clock. Actual tensor shapes/dtypes/devices and image grid values are
recorded without pixels, token content, IDs, dataset paths, credentials or GT.

Each GPU has allocated/reserved bytes, lifetime peaks, free/total, active and
inactive-split bytes, allocation retries/OOM counts where available, allocator
backend/config and explicit null/unavailable reasons. Peaks reset once before
load, never per-image; they are **lifetime**, not claimed interval peaks. Boundary
values support trend analysis; snapshots can miss transient asynchronous peaks.

Failures preserve original class/module/message and cause chain, stage/active
native hooks and relative module/function/line stack without locals or source
lines. Normal CUDA OOM messages remain verbatim. Absolute paths/credentials are
redacted; truncation/redaction is explicit. Best-effort scalar stats cover both
GPUs; observer failure never replaces the original exception. Disk exhaustion or
process termination can leave torn/missing diagnostics; custody retains them and
the audit cannot mark such observations complete. No tensors, allocator dump or
private history API is retained.

No explicit CUDA synchronization/profiler is added. Reading the small grid via
`.tolist()` can cause a device-to-host synchronization; hooks/stat calls/fsync
also add overhead and can change timing/allocation behavior. These diagnostic
conditions are declared and need approval. Native GPU hooks/Accelerate dispatch,
async error attribution and overhead are **not validated by CPU doubles**.
The inherited 10-second nvidia-smi sampler remains PARTIAL_SAMPLED and includes
device usage beyond this process. It is not a sub-second peak measurement.
